# PhotoCraft

PhotoCraft is a Rust image editor whose desktop app, CLI, and agent interfaces share a command engine. Choose the interface that fits the task and verify output before presenting it. Keep an original unless the user asks to replace it.

- For inspection, image edits, format conversion, command discovery, and batch work, read [CLI and Documents](cli.md).
- For headless MCP, persistent sessions, or control of a running desktop window, read [Agent Automation](automation.md).
- For installation, release selection, version differences, and troubleshooting, read [Installation](installation.md).

The upstream repository is [storytold/photocraft](https://github.com/storytold/photocraft). Its documentation and the installed binary can describe different versions. Check the installed binary's help before relying on a flag or command.
